Modulo 3 - Desafio 3
## FUNCIONES 4x1
![HTML5](https://img.shields.io/badge/html5-%23E34F26.svg?style=flat&logo=html5&logoColor=white) ![CSS3](https://img.shields.io/badge/css3-%231572B6.svg?style=flat&logo=css3&logoColor=white) ![JavaScript](https://img.shields.io/badge/javascript-%23323330.svg?style=flat&logo=javascript&logoColor=%23F7DF1E)

El desarrollo de este desafio es para poner en practica los conocimientos adquiridos con respecto de uso de Funciones para la modificacion del DOM a partir de un evento generado por el usuario sobre la pagina.

1. Transformar una declaración de función a una función de expresión.
2. Transformar una función de expresión a una arrow function de una línea.
3. En una pagina poner 4 cuadrados de diferente color y al hacer click sobre ellos, deberan cambiar a color negro.
4. En una pagina poner un cuadrado de color blanco que ira cambiando de color segun la tecla que sea presionada:
   - Tecla a o A = rosado
   - Tecla s o S = naranjo
   - Tecla d o D = celeste
5. Adicionalmente si se presionan las teclas [q],[w] o [e] se creara un nuevo cuadrado con el siguiente color:
   - Tecla q o Q = amarillo
   - Tecla w o W = azul
   - Tecla e o E = cafe
